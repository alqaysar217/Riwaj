# **App Name**: Riwaj | رواج

## Core Features:

- Artisan Product Catalog: A multi-category digital catalog focused on Yemeni exports like coffee, honey, and handicrafts with a high-fidelity visual layout.
- Cultural Storyteller Tool: An AI tool that uses reasoning to craft authentic, evocative product narratives based on seller-uploaded photos and basic specs.
- RTL Native Checkout: A streamlined checkout process specifically optimized for right-to-left languages, supporting various regional payment indicators.
- Small Business Storefronts: Dedicated digital spaces for local productive families to list goods and manage their small-scale inventory.
- Seller-Customer Secure Messaging: Real-time chat functionality stored in the application database to allow direct inquiries between buyers and artisans.
- Artisan Store Directory: A map or list-based directory allowing customers to discover and follow local specialty stores based on their heritage expertise.
- Verified Trust Profiles: Merchant profiles showcasing customer ratings, heritage certificates, and identity verification stored in the persistent database layer.

## Style Guidelines:

- Primary: #0F766E (Emerald Green), representing the fertile richness and growth of the Yemeni landscape.
- Accent: #D4A017 (Luxury Gold), utilized for highlighting premium goods and key call-to-action buttons.
- Background: #FAFAF9, a light, warm neutral that mimics the color of traditional stone masonry.
- A font pairing featuring 'Alegreya' (serif) for evocative headlines and brand-heavy text to provide a literary, premium feel, and 'Poppins' (geometric sans-serif) for functional UI elements.
- Monolinear icons with refined curves, maintaining a modern and clean aesthetic across the RTL navigation bar.
- An 8pt grid system with an emphasis on breathable white space to reflect a high-end, uncluttered marketplace experience.
- Sophisticated micro-interactions using ease-in-out transitions when expanding categories or filtering the marketplace.
